Délai de publication

Temps d'affichage du bandeau « nouvelle mise à jour disponible » avant que le changement apparaisse sur le site.

Comment ça fonctionne : ce back-office et le site principal partagent leurs données via le stockage local de votre navigateur. Les mises à jour sont donc instantanées entre les onglets ouverts sur cet ordinateur. Pour que tous les visiteurs, sur tous les appareils, voient vos changements en direct sans que vous ayez à re-téléverser le site, il faut connecter les deux pages à une vraie base de données (un petit service comme Firebase ou Supabase, par exemple). Je peux vous aider à mettre ça en place si vous le souhaitez — dites-le-moi.
Les modifications sont enregistrées automatiquement en brouillon. Cliquez sur « Publier » pour les envoyer sur le site.
